# Push_swap

Push_swap is a project developed as part of the 42 curriculum that consists of sorting a stack of integers using a limited set of operations and the smallest possible number of moves. The project involves implementing sorting algorithms and optimizing their performance to efficiently handle different input sizes. It focuses on algorithm design, data structures, sorting strategies, and performance optimization in C.

**Technologies:** C, Algorithms, Data Structures, Sorting Optimization, Makefile, Git.
